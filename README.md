# LoLM — Local Language Model

Dự án chạy Large Language Model hoàn toàn local trên máy tính cá nhân.

## Phần cứng
- GPU: AMD Radeon RX 7900 XTX (24 GB VRAM)
- Backend: Ollama với ROCm/Vulkan
